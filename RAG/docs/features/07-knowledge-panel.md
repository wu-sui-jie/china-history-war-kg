# F07 可视化知识面板

- 功能编号：F07
- 状态：已完成（RAGv3 前端渲染；**地图模块于 RAGv5 2026-09-15 启用**——地点坐标覆盖 4,819/5,316，
  见 [RAGv5-开发说明](../RAG_v1/RAGv5-开发说明.md) §4.13/§4.14；其余实现见 [RAGv3-开发说明](../RAG_v1/RAGv3-开发说明.md)，
  任务分析见 [RAGv3-规划分析](../RAG_v1/RAGv3-规划分析.md)）
- 创建时间：2026-09-03

## 功能作用

在问答页面右侧展示与当前问题相关的图谱子图、时间线、地图位置和证据原文，让 RAG 的回答不只是文字，而是可交互的知识展示。

## 用户场景

1. 用户问某场战争，右侧展示该战争的一跳图谱。
2. 用户问多个事件之间的关系，右侧展示事件子图，关系链由子图内的关系连边承载
   （不单独设“关系路径”视图，见模块清单第 3 项）。
3. 用户问地点相关问题时，右侧可展示历史地图或现代位置。
4. 用户点击图谱中的节点后，可以继续追问该实体（画布内节点与下方实体按钮均可点击）。

## 知识面板模块清单

1. 当前实体信息卡：展示问题涉及的事件、人物、组织、地点等实体基础信息；事件卡额外展示
   攻方、守方、作战行动、地点与历史影响（2026-09-20 起从快照 `event_cards` 装配，
   字段口径见 [data-contract.md](../data-contract.md) 的 `entity_cards` 段）。
2. 图谱子图：展示当前事件或实体的一跳关系，关系边带类型标签。
3. 关系路径：**未单独设视图**——事件之间的关系链由图谱子图（第 2 项）的关系连边承载；
   F05 panel 数据不输出独立路径字段，独立路径视图属后续增强（决策见 F03 两跳路径策略）。
4. 引用与证据：展示回答引用的证据原文、来源和置信度。
5. 时间线：当问题包含多个事件或时间信息时，展示相关事件时间线。
6. 地图：当问题涉及有坐标的地点时，展示地图位置；无坐标时降级为地点列表。
7. 节点追问：图谱节点（画布内节点与下方实体按钮）支持点击，直接生成“介绍一下 XX”式
   追问；原设想的“继续提问该实体 / 查看实体详情”操作菜单未实现。

## 模块展示策略

1. 默认展示：当前实体信息卡、图谱子图、引用与证据。
2. 条件展示：时间线、地图根据问题类型自动出现（**当前为标签页手动切换**，未实现按问题类型
   自动切换标签；每轮新消息重置回“引用证据”标签页）。
3. 知识面板采用标签页或折叠区域，避免同时堆叠过多内容。
4. 点击图谱节点继续提问时，生成“介绍一下 XX”式追问语句（“XX 参与了哪些战争”等
   多句式追问未实现）。

## 输入与输出

- 输入：当前问题、回答正文、SSE 中的 panel 数据、图谱证据、文本证据。
- 输出：实体卡、图谱子图、时间线、地图点、证据列表。

## 实现思路

1. 使用前端图表库绘制图谱子图和时间线。
2. 地图数据根据地点经纬度生成，缺失坐标时降级为文字列表。
3. 每个证据卡片可展开原文，并支持从回答引用跳转。
4. 知识面板数据格式由后端统一返回，前端只负责渲染。
5. 初版地图使用现代底图加历史地点标记；历史地图底图需要额外素材和授权，后续再评估。
6. citations 或 fusion 事件携带 conflicts 时，证据卡片可显示“存在不同说法”标识。
7. 知识面板优先消费 SSE 的 panel 事件；子图数据结构遵循 data-contract.md。

## 数据基础与降级策略

1. 时间线按事件 start_date 排序；时间缺失或仅到朝代时，归入“时间不详/仅知朝代”分组，不强行插入时间轴。
2. 事件时间解析规则需要在 F09 治理报告中记录。
3. 地点坐标覆盖率由 F09 治理报告评估；覆盖率不足时，地图模块以地点列表为主。
4. 坐标缺失的地点不报错，自动降级为文字地点卡。
5. 事件卡的叙事字段（攻方/守方/作战行动/历史影响/地点）缺失时整行不渲染，不做空占位。

## 依赖与前置条件

1. 图谱检索结果包含可绘制的关系数据。
2. 地点数据包含可用坐标或文本位置。
3. 前端页面已经预留知识面板区域。
4. 前端图表组件支持节点点击事件。

## 验收标准

1. 演示问题时知识面板不会空白。
2. 图谱、时间线、地图等模块互相不遮挡。
3. 没有坐标的地点不会导致页面报错。
4. 点击图谱节点可以发起新的追问。
5. 时间缺失或坐标缺失时，知识面板有明确的降级展示，不出现空白模块。

## 已确认需求

1. 知识面板采用本功能文档列出的模块清单。
2. 支持点击图谱节点继续提问。
