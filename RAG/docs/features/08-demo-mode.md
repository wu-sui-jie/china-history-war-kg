## 功能作用

为比赛评审、老师和访客提供无需配置即可体验的演示入口，用示例问题展示系统的不同能力。

## 用户场景

1. 访客打开页面，看到一组示例问题，点击即可提问。
2. 评审希望看到关系问答、背景问答、时间线问答等不同能力。
3. 现场演示时不需要输入复杂 prompt 就能展示完整效果。

## 输入与输出

- 输入：示例问题（无需演示模式开关——示例区在欢迎页常驻展示，`config/defaults.py` 无 `DEMO_MODE` 配置项）。
- 输出：一键提问、引导文案、能力分类标签。

## 实现思路

1. 设计一组覆盖不同能力的示例问题，例如单实体事实、人物生平、因果关系、地点战争、时间线等。
2. 页面首页直接展示示例问题，不以教程式长文为主要内容。
3. 可提供“关系型问题”“背景型问题”“时间线问题”等分类标签。
4. 演示模式不设置登录墙，默认使用可运行的低成本配置。

## 依赖与前置条件

1. 至少一组经过验证、结果稳定的演示问题。
2. RAG 核心链路可用。

## 验收标准

1. 页面打开即可提问，不需要输入账号。
2. 示例问题点击后能稳定返回完整回答。
3. 示例问题能覆盖图谱检索和文本检索两类能力。
