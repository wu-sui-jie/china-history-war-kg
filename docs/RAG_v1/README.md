# RAG 开发文档（RAG_v1/RAGv2/RAGv3 阶段归档）

本目录存放按阶段推进的开发说明，与 `../README.md`（功能需求索引）分开：

- `../README.md`（总览）与 `../features/`：**需求是什么、怎么验收**（功能文档）。
- 本目录（RAG_v1/）：**代码实际做到了什么、对应哪些文件、怎么跑、下一步做什么**（开发记录）。

> **时效说明（2026-09-20 整理）**：本目录各文档写于**各自的阶段当时**，正文里的
> “进行中 / 未开工 / 待提交 / 尚未入库”等表述属于当时状态，不代表现状。
> **现行事实（版本、测试数、门禁状态、数据计数、发布状态）一律以
> [../current-status.md](../current-status.md) 为准**；本目录的用途是复盘阶段决策与追溯改动来源。
