# F10 问答效果评测

- 功能编号：F10
- 状态：待开发
- 创建时间：2026-09-03

## 功能作用

通过固定问答集和评测指标，持续验证 RAG 问答系统的效果，并为比赛材料提供量化证据。

## 用户场景

1. 开发过程中判断检索和回答是否达到预期。
2. 对比图谱加文本双通道与纯文本 RAG 的效果差异。
3. 输出评测报告用于参赛方案和技术说明。
4. 答案最终正确性由人工评分，不默认使用模型评分。

## 输入与输出

- 输入：黄金问答集、相关文档标注、RAG 系统输出、真实数据治理报告。
- 输出：人工评分表、评测报告、错误样例、指标统计。

## 实现思路

1. 建立 30 到 50 条黄金问答集，覆盖实体介绍、关系、因果、时间线、背景等类型。
2. 黄金问答集由人工审核和确认。
3. 答案正确性、引用正确性等主观结果采用人工评分。
4. 检索召回、图谱命中、耗时等客观结果可以由脚本自动统计。
5. 同一问题可运行不同检索配置，保存对比结果。
6. 评测脚本输出指标报告和失败案例，便于后续优化。
7. 人工评分需要提前定义评分说明，避免不同审核人标准不一致。

## 人工评分规则

1. 答案正确性评分：
   - correct：答案正确且依据充分。
   - partial：答案方向正确但信息不完整。
   - incorrect：答案错误。
   - unknown_answer：应拒答时正确拒答。
2. 引用正确性评分：
   - supported：引用可验证且支持答案。
   - unrelated：引用存在但与该结论无关。
   - unsupported：关键结论没有引用支持。
3. 每条评测记录保存问题、系统答案、人工评分、备注和对应证据。

## 检索召回标注

1. 黄金问答集中的每条问题预先标注应该被召回的相关文档或实体。
2. 标注结果用于计算 recall@5、图谱命中率等客观指标。
3. 相关文档标注由人工完成，并在评测报告中记录标注版本。

## 依赖与前置条件

1. 黄金问答集需要人工审核，确保答案可依据现有数据回答。
2. RAG 核心检索和生成链路已完成。
3. 人工评分说明已确定。
4. 相关文档标注已完成。

## 验收标准

1. 评测可以在一条命令下重复运行。
2. 报告能区分答案错误、引用错误、检索失败和无证据问题。
3. 可以输出“图谱加文本双通道”与“纯文本检索”的对比结论。
4. 人工评分结果可导出并逐条复核。

## 题库统一说明

1. F08 恢复开发后，示例问题与 F10 黄金问答集使用同一题库管理。
2. 示例问题从已通过人工审核的评测题中挑选。

## 已确认需求

1. 黄金问答集由人工审核。
2. 答案正确性采用人工评分。
