## 二、A-2：进度文件一批一个

`geocoding_progress.jsonl`（所有批次共用一个只增不减的文件）→
`geocoding_progress_<run_id>.jsonl`，`run_id` = 本地时间到毫秒。

- 为什么带毫秒：只到秒的话"同一秒内连开两批"会撞名，又退回成多批共用一个文件。
  即便如此，同一毫秒内连开两批仍会撞（实测：用例里连跑两批恰好落在同一毫秒），
  所以 `new_run_id()` 再拿一个进程内序号兜底——**文件名唯一**是"一批一个文件"的前提。
- 清理口径：新增 `prune_progress_files(keep=20, progress_dir=None)`（**不自动跑**，删文件是显式动作），
  在 `war_extraction/geocoding/README.md` 里给出调用命令。
- `batch_geocode` 内部顺序调整为"先定 run_id、再推导默认进度路径"，显式传 `run_id` 时文件名也会带上它。

**验收**：用例 `test_two_default_batches_produce_two_files` 断言两批各得一个文件、各自只含本批记录；
把 sentinel 分支改坏时新增的 2 例失败（见第九节）。

## 三、A-3：日配额截断不再"悄悄跑完剩下的流程"

`AmapGeocoder` 新增 `batch_aborted_by_quota`（日配额提前结束整批时置位），新增模块函数
`warn_if_quota_truncated(geocoder)` 打醒目提示。调用侧：

| 调用方 | 行为 |
| --- | --- |
| `load_and_geocode`（仅编码那一步） | 保存结果前打提示，照常返回（本步没有下游副作用） |
| `run_full_pipeline`（pipeline） | 打提示后**默认在编码后停下**，不进入审核 / 导入；要拿部分结果继续必须显式 `--allow-partial` |

为什么默认停：`pipeline` 的下一步是"审核 → 导入数据库"，被截断时人会以为"这批跑完了"，
把半份结果当成全量入库——这正是工作单里"调用方原本预期跑完所有地点"的风险点。

**验收**：`tests/test_geocoding_pipeline.py` 2 例（桩掉配额错误）：一例断言提示出现且不进入审核/导入，
一例断言加 `--allow-partial` 后流程走完；把早退分支改坏时 2 例都失败。

### C-6（中）：关系类型必须精确相等 + 阈值敏感性分析

**修的是什么（比工作单初稿更严重）**：五个规范事件-事件关系类型**两两 `fuzz.ratio` 都是 50**
（都带"关系"二字、4 字中 2 字），而关系类型原先只做模糊比对（阈值 40）——**全部过阈值**，
于是类型判错也拿满分。工作单的实测表复现无误：标注 `(E1, 顺承关系, E2)` 对上预测
`(E1, 因果关系, E2)` 与 `(E1, 并列关系, E2)` 修前都是 tp=1。

**改法**：`OptimalEvaluator.relation_types_match()`——两侧都落在规范集合内要求**精确相等**，
其余自由文本关系名仍走模糊比对（事件-地点/人物/组织那类的写法不唯一，模糊本来就对）。
`filter_relations` 的预筛**保持原样**（类型错的预测仍作为 FP 计入，而不是被筛掉后不算账）。

**结论（写进报告时必须带上）**：

1. **事件指标对 `event_sim_threshold` 高度敏感**：0.25→0.55 时事件 F1 从 0.4606 掉到 0.3430，
   **极差 0.1176**（宏观平均 F1 极差 0.0430）。所以"事件 F1 0.4175"这个数**必须与阈值一起读**，
   单独引用会误导（"调参刷分"的空间就在这里：把阈值降到 0.25 就能换来 +0.043 宏观 F1）。
   当前 0.35 落在区间中段，不是悬崖边。
2. **关系指标对 `relation_threshold` 最敏感**（极差 0.0538），但**改完之后它的敏感性来源变了**：
   规范事件-事件类型走精确比对、不再受阈值影响，剩下的敏感性只来自自由文本关系名——
   口径上比改前更干净。另外 60→70 处出现非单调（0.6816→0.6835），引用单点数值时别把趋势读过头。
3. **实体指标对它的阈值几乎不敏感**（极差 0.0056），且与其它三个阈值完全无关。
4. 重跑本分析的命令：`python tools/threshold_sensitivity.py`（约 8 分钟；产物指纹会打在表头，
   避免把"产物换代"误读成"阈值敏感"）。
