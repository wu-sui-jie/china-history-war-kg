## 二、R1：复核发现的回归与阻塞项

### R1-1 开发态节点 CRUD 与总览搜索断裂（高）

**成因**：第 1 轮把接口 baseURL 从 `http://${hostname}:5000` 改为同源相对路径 `/`，但 vite 代理只有 `/api` 与 `/rag` 两条规则。不带 `/api` 前缀的旧接口（历史直接挂在 Flask 根路径上）于是打到 Vite 自己，被 SPA fallback 返回 `index.html`，axios 解析 JSON 报错。

**修复**（方案 A，最小改动）：vite 代理增加一条精确正则：

```ts
'^/(create_node|update_node|delete_node|search_name_kg|user/(menu|permission))$'
```

**排查范围**（避免只修一半）：逐个核对了前端所有 `Http.*` 调用形态，不带 `/api` 前缀的共 6 条路径——四个节点管理页的 `/create_node`、`/update_node`、`/delete_node`（各 4 处），`OverviewGraph` 的 `/search_name_kg`，api 层的 `/user/menu`、`/user/permission`。另外发现 `/login/verificationImg`、`/login/loginQrcode` 是**死接口**（后端无此路由、模板也未使用），已随 FE-6 一并删除，故不纳入代理。

**验证**（在真实运行环境，非打桩）：你本机的 dev server（:3001）与后端（:5000）都在运行时，配置变更被 Vite 自动重载——

| 请求 | 结果 |
| --- | --- |
| `/create_node`、`/update_node`、`/delete_node`、`/search_name_kg`、`/user/menu`、`/user/permission` | 全部 401 + 后端 JSON（`{"code":401,...}`）→ 确认转发到 Flask |
| `/knowledge/timeline`、`/workspace/dashboard`、`/static/index.html` | 200 + `text/html` → SPA fallback 与静态资源不受影响 |

### R1-2 CI 的 Python 3.8 在 ubuntu-24.04 上装不到（高）

`legacy-backend` job 原为 `runs-on: ubuntu-latest`（现已是 24.04 镜像），而 `actions/setup-python` 在 24.04 上不提供 Python 3.8（已 EOL），一推上去就 `Version 3.8 was not found`。已把该 job 单独钉到 `ubuntu-22.04`，并在注释里写明原因；同文件的 3.9 语法兜底 job 不受影响。

### R1-3 Neo4j 孤儿节点与按名回退（中）

两处都补上：

1. **按名回退改为「同名唯一才动」**：新增 `DbUtil._find_neo4j_by_name()`，取全部同名匹配并按类型过滤——唯一才返回，多于一个返回说明（`Neo4j 中有 N 个同名同类型节点，需人工核对后再处理（本次未改动 Neo4j）`），删除与改名两条路径共用它。`delete_node` 与 `update_node` 都改了（改名动错节点同样是数据损坏）。
2. **孤儿清理**：`sync_sqlite_to_neo4j.py` 新增 `collect_orphans()` 与 `prune_orphans(execute=False)`——默认只打印清单演练，加 `--yes` 才真删；判定同时看 `neo4j_id` 与 `(标签, 名称)`，任一命中都不算孤儿（宁可漏报也不误删）。`run()` 结束时打印一行提示，让这个能力可被发现。

**验证**：① 单元层面构造 0/1/2 个同名节点与类型不同的同名节点，覆盖 delete 与 update 两条路径共 8 条断言，全部通过；② 在真实 Neo4j 上跑 `--prune-orphans`（演练模式，只读）：**未发现孤儿节点**，说明当前两侧节点集合一致。

### R1-4 iframe sandbox 的描述需如实降级（低）

`allow-scripts` + `allow-same-origin` 对同源页面不构成隔离（iframe 内脚本可直接访问父页面，也能移除自身 sandbox 属性）。已把 `RagAssistant.vue` 的注释改为明确写「这**不是安全隔离**」，并说明真正的隔离要靠 RAG 独立域名或反代层鉴权；`docs/项目审查与修复清单.md` 的 SEC-9 行与第 1 轮实施记录同步降级措辞。

| 假设 | 实测 |
| --- | --- |

| 90s 超时是本次改动引入的 | **证伪**：运行中的 dev server 仍用改动前的默认 `load_all=True`；重启后走限量分支，0.78s |
