### W2 inference 页模板拆子组件 + any 清理（绑定做）✅ 已完成

**干什么**：`frontend/src/views/inference/index.vue` 现 1161 行（模板约 352 + 脚本约 800）。把模板按 UI 块拆成子组件，同时清掉页面里剩余的 `any`（约 170 处的大头在此页）。这是 FE-7 / P2-2 的最后一步。

**怎么干**（坚持"先测试后拆"）：

1. 拆分边界（按 UI 块，建议四个子组件，放 `views/inference/components/`）：
   - `SessionSidebar.vue`：会话列表、提问历史、新建/改名/删除 —— props: `sessions / activeId`，emits: `select / rename / delete / create`；
   - `ChatMessages.vue`：消息气泡、思考过程、引用证据渲染 —— props: `messages / generating`，emits: `regenerate / copy`；
   - `ChatInput.vue`：输入框、发送/停止 —— props: `disabled`，emits: `send / abort`；
   - `KgContextDrawer.vue`：知识面板抽屉（引用证据/实体卡/子图/时间线/地点五个 tab）—— props: `context`，emits: `close`。
2. 顺序：每个子组件**先写挂载测试**（mock 数据传 props，断言渲染与 emits）→ 把模板块搬进子组件 → 父页面模板替换为子组件标签 → 跑 `pnpm test` 全绿再拆下一块。
3. any 清理跟在同一批：子组件 props/emits 全部显式类型；页面里 `ref<any>` 逐个换成具体接口（`ChatMessage / SessionMeta / KgContext`，定义进 `src/types/`）。每清一批跑一次 `vue-tsc`（`pnpm run build:check`）。
4. 样式已外移（index.css），子组件需要的样式按 class 原样引用即可，**不要搬动**，避免视觉回归。

**验证（已完成）**：`build:check` 0 错误；`pnpm test` **133 passed**（94 + 新增 39）；页面 **403 行**（当时记的 400 行有误，第 10 轮已核准为 403）；浏览器**脚本化**过了一遍（`scripts/smoke-inference-page.mjs`，17 项断言计算样式与交互，含提问/切会话/图谱展开/导出/按账号落盘）——并由它抓到 `isFirstLoad` 未复位这个回归。

> **第 4 条需要修正**：`index.css` 是父组件 scoped 样式，**不能「按 class 原样引用」**——scoped 只作用于父模板的元素，子组件内部匹配不到；直接去掉 scoped 又会与 9 个重名 class 互相污染。实际做法：按页面根元素加 `.inference-container` 命名空间前缀（等价于手写版 scoped，规则内容与顺序未动），迁移脚本自带等价校验。详见[第 7 轮记录](修复实施记录-第7轮-20260925.md)第二节。
