## 四、后续计划（按顺序，每条含验收标准）

**阶段 0：收尾本轮（可立刻做，低风险）**

- 删除 `backup.cmd`（或清理其中的代理端口与私人仓库名）→ 验收：`git status` 干净、清单 DOC-4 勾掉；
- 本机路径在 README 启动命令里改成 `conda activate` 口径（去掉盘符解释器路径）→ 验收：README 正文不再出现 `E:/`；

**阶段 1：把"不可复现"这件事解决掉（建议下一个动作，收益最高）**

- 修 EER-15：让模糊匹配在相似度并列时用稳定键打破平局（如同一相似度取名称字典序）；
- 补一条"同一输入跑两次结果一致"的用例；
- 验收：`python evaluate.py` 连跑两次，`results.json` 除 `evaluated_at` 外逐字段相同；
- 顺带在 `evaluate.py` 的 docstring 里写明：评估数字受「pred 产物换代」与「匹配定序」两类因素影响，对比两次评估前先确认 pred 是同一份（第 5 轮就出现过把「产物换代」误读成「公式改动效果」的混淆）。

**阶段 2：EER 工程债分批收口**

- 先做有明确 bug 的：EER-4（正则）、EER-11（缓存索引原子写 + TTL）、EER-12（geocoding 重试退避）；
- 再做结构性：EER-7 剩余（backend 不再复制抽取编排）、EER-6（四份 JSON 解析等重复收敛）、
  EER-10（两套评估器二选一）；
- 最后把 EER 的用例挂进 CI（从"评估可复现"这条用例开始）；
- 验收：每条改动都有自己的用例或可复现命令；`compileall` + `ruff` + 既有用例全绿。

**阶段 3：部署前**

- 在干净 commit 上完整演练一次 RAG 发布（RAG-8）；公网形态下启用 nginx `auth_basic`（RAG-1）；
  按需评估方案 B；
- 验收：发布包 smoke 通过、`/api/health` 版本与产物一致、`auth_basic` 打开后匿名访问被拒。

**阶段 4：不定时**

- `git filter-repo`（对外贡献变多前一次性处理）；
- 前端剩余 `any` 清理与类型收敛（随页面改动顺手做）。

## 六、接手须知（怎么继续）

1. **先读什么**：本文件 → [docs/README.md](README.md)（文档总索引）→
   [项目审查与修复清单](项目审查与修复清单.md)（逐条状态）→ 最近一轮
   [修复实施记录](修复实施记录-第7轮-20260925.md)（改法与前车之鉴）。
2. **改代码前的固定动作**：
   - 改旧后端接口 → 先 `python tools/snapshot_responses.py capture --out before.json`，改完重启再 `diff`，
     必须"完全一致"或逐条解释差异；
   - 改旧前端页面 → 先跑 `pnpm test`（133 例），改完再跑 + `build:check`；页面级改动加跑
     `node scripts/smoke-inference-page.mjs`；
   - 改 RAG 前端 → `npm run test:unit` + `test:component` + `typecheck`，隔离相关再跑
     `npm run test:e2e:offline`；
   - 改抽取链 → `pip install -e entity-event-relation` 后跑 `backend/tests`，并做一次评估冒烟。
3. **每轮收尾的固定动作**（第 4 轮定下的约定）：跑验证 → 勾选工作单 → 写当轮实施记录 →
   回写清单状态 → 最后提交"记录本身"。
4. **文档纪律**：数字只写一处（RAG 的进 `current-status.md` 并由 `check_docs.py` 核）；
   跨模块约定写在 `docs/`；过程性记录收口后压缩（先例见 `RAG/docs/CHANGELOG.md`）。
5. **两个环境别混用**：旧后端/抽取用 Python 3.8（`place-name-KG`），RAG 用 3.11（`AI_Agent`）。
6. **本机的坑**（都踩过、都记在文档里）：Git Bash 下 `/tmp` 与 Python 看到的 `/tmp` 不是一处、
   带前导斜杠的参数会被 MSYS 改写、`pkill -f app.py` 杀不掉 Windows 进程（用 `netstat -ano` +
   `taskkill /F`）、`vue-tsc -b` 掉出来的 `vite.config.js` 会盖住 `.ts`。
