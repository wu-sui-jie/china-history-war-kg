## 用法

1. **它的用途之一是"范围对齐的评估产物"**：参考集只覆盖这三个子集，而整本产物覆盖全书，
   拿整本产物去评 dev 会把范围外的事件全算成假阳性（实测精确率被压到 6.8%）——
   所以在子集上各跑一次抽取，得到范围与 dev/test 一致的产物（**dev = 唐 + 秦汉、test = 明**）。
   **但它不能替代整本重跑**：下游（Excel / SQLite / Neo4j / RAG）要的是全书产物。
2. （历史提醒）它最早是**参考集重建的输入**，那时的告示是"不要拿它跑正式抽取、草稿要等第二轮
   代码收口与模型定案"（依据第一轮核验记录第 4 节；该过程文档已随收口删除）——第二轮已收口，那条限制随之失效。
3. 核验人员按这里的字符 offset 回原文定位：
   `子集内 offset + 起始 offset = 全书 offset`。
3. 事件粒度、证据口径以 `data/annotations/README.md` 为准。
