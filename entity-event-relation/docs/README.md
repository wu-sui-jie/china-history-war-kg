## 一、这一轮（整改阶段 0~4）做了什么

**起点**：指标低得没法解释——但那不是模型差，而是**分母不可信**（参考集是"几个模型分片汇总、
字段没做人工处理"）＋**评估器与抽取链各有结构缺陷**。所以这一轮按"先让分母可信、再修抽取"
的顺序做了四件事：

1. **修评估口径与评估器**（阶段 2/3）：去掉 `check_exists(gold)` 预过滤、事件映射加朝代/年份/地点
   语义约束、两套身份口径并列报告、事件字段加值准确率、metadata 分 `predictions`/`evaluator` 两组。
2. **重建参考集**（阶段 1，人工线）：三个子集逐条核验（11,044 行判定）→ 明子集 20% 双标出 **IAA**
   →246 条分歧逐条仲裁 →成稿 `data/annotations/v2/` + **dev/test 切分**。结构自检四项归零
   （`head` 不在事件表 0/旧 605、`tail` 0/旧 549、重复关系行 0/旧 22、残缺年份 0/旧 14）。
   **这是"指标能不能信"的前提。**
3. **修抽取链与提示词**（第三阶段 E 组）：15 项改动，重点是关系层——规则派生的 `统帅` 改为 `将领`、
   关系角色必须由原文直接写出、事件关系的 `A` 按原文时序在前；事件字段层收紧 `StartDate`/`Place`/
   `Result`/`OrgName`/`Role`/`OrgType` 的判定。**依据不是猜**：B 组那 350 条人工判定给出
   "42 条关系错**全部**是类型判定错或方向标反，零条是证据不足"，改动方向就是照这个结论定的。
4. **整本重跑 + 发布**（阶段 4 + 批四）：211 段 × 3 阶段（约 633 次调用）换代产物 → 导出 Excel →
   导入 SQLite → 全量同步 Neo4j → RAG 快照 + 索引 + 激活 → 前端验收。

**过程里另修掉 5 个不在计划内的真缺陷**（都是"静默"那类，只有端到端跑一遍才显形）：
关系阶段因模型输出扁平数组而**整段降级**（4/29 段）、导入器的乱码"修复"**把正常中文改坏**
（268 个值）、产物的**关系目标端从没被校验**（167 条边被静默丢掉）、导入器的跳过条数**不计数**、
以及**缺一个与时间无关的内容哈希**（导致两版产物无法按"内容"比对）。

## 三、还剩什么

**登记在册、待决定（不阻塞使用）**：

1. **8 条关系没进库**（0.05%）：产物把关系头**标准化**、而库里事件名是原始写法，导入器精确查找对不上。
   两条修法：产物侧按同一口径过滤，或导入器支持标准化名兜底。
2. **RAG 词典仍是从数据推导的**（未以权威表为种子）：所以它收了 `交战`（判定为"不加入"）、
   丢了 `政治事件`/`议和`。要落地得改 `RAG/data/snapshot/governance.py` 的词典构建。
3. **可选改进（进缓存键，要攒批重跑）**：固定随机种子（现在 `seed` 恒为 `null`，实测同一文本两次跑
   关系数差约 10%，任何 A/B 比较都被这层噪声压着）；system prompt 里用户输入的位置（提示词注入防护）。

**已判定不做，理由留档**：
- **E4 过宽概括扩表**：参考集已按事件粒度口径把那类判掉，产物继续输出会被算 FP——**这个惩罚是对的**，
  改表属"改进"而非"纠错"；（判定材料：`evaluation/review/overbroad_candidates_20260927.md`）
- **E5 真实语料 few-shot**：验收口径要**人工**抽样判定（或接受有偏向的 gold-F1 代理），
  而噪声下限可能盖住效果；性价比不成立。

**下一轮的改进入口**：「关系:事件-事件」是当前最弱的一层（抽样 57.1%，14 行；与"错误类型最大一类是
**关系类型**"一致）——**要改就改这里**，事件字段层这一版已持平。

**评估口径的一个结论**（对"要不要做全书参考集"的回答）：**不做**。随机抽样判定更便宜、天然覆盖全书、
且跨版本可比；全书参考集的 5 倍人力只换来"没有抽样误差"这一项，而标注自身噪声可能更大。
局限如实标注：抽样只测**精确率**，答不出召回率；真要召回率时，对 20~30 个随机段做一次小规模 gold 即可。

## 五、归档规矩

1. **只归档、不删除**：被取代的过程文档移到 `archive/`，**原文一字不改**（只在开头加一行横幅说明
   它被哪份取代），`git mv` 保留历史。
2. **归档件不再更新**：它的结论若还有效，已经并入上面"现行"的文档；以现行文档为准。
3. **相对链接必须有效**：归档时重算所有相对路径（有 `tools`/脚本可查；本轮顺手修掉了 5 条**本来就存在**
   的失效链接）。
