## 0. 先记住三条路径（它决定每批怎么验）

| 路径 | 花钱 | 拿到什么 | 适用 |
| --- | --- | --- | --- |
| **干跑**（在旧产物上直接调函数） | 免费 | 只有数字，不改产物 | 规则类改动（派生关系、方向、发布过滤、字段后处理） |
| **缓存重放** | 免费 | 一份新产物，但**新旧规则的结果并存** | **别当生效用**（实测：`统帅` 与 `将领` 会同时出现） |
| **全额重跑** | 全额（整本 **211 段 × 3 阶段 = 633 次调用**；文档旧写的 196 是 2026-08-18 那次的分段数，分段器在 09-26 改过） | 唯一干净的产物 | 提示词 / `config/*.json` / `models/*.py` / 模型名 的改动 |

**进缓存键的只有这五类**：`prompt_version`（提示词目录）、`config_version`
（`aliases` / `relation_types` / `dynasty_ranges` / `publish_rules` 四份）、`schema_version`
（`models/*.py`）、`model_name`、分段参数。**改这五类之外的东西都不该付重跑的钱。**

### 3.07 删掉"证据为空 / 目标为占位词"的关系（判定：删，2026-09-27）

**判定**：项目负责人决定**删掉**那 4 条（§3.06 之后单列出来的那批）。

**为什么值得动**：其中 **2 条已经进了发布子集**（`元朝靖北方诸王之乱 —主战场→ 漠北`、

**实现**（`main.py` 的 `_drop_dangling`，与既有的"悬空边"丢弃同一处）：

- 新增两条规则：**证据为空**的边丢掉；**目标是占位词**（`不详`/`未知`/`无`…，
  取自 `value_parsing.PLACEHOLDERS_FULL`）的边丢掉——占位词不是实体，是"没抽到"的写法。
- 新增两个计数键（`empty_evidence` / `placeholder_target`），**不做静默丢弃**（同函数既有的承诺）。

**怎么应用**：**带缓存重放**（免费，7 分钟；真实跑批是 2 小时）。这是合法的：
规则是**纯后处理过滤**，挂在合并之后，对命中的缓存分段一样生效——不像抽取侧改动会出现
"新旧规则结果并存"（那是缓存重放不能当生效用的原因，见 §0）。

**实测**：4 条**精确删除、无连带**（关系总数 16670 → **16666**，"证据为空的关系"门禁 **4 → 0**，
发布子集里那 2 条也没了，其余门禁不变、对照退出码 0）。

**顺带修的一个洞**：**全缓存命中时 `model_served` 是 `None`**（它取自响应，没调用就没有）。
而缓存重放恰恰是文档推荐的免费路径、产物又要发布进知识库（`current_dataset.json` 也抄它的
metadata）——于是每走一次免费路径就把产物的"模型自证"抹掉一次。现在在保存路径上加了**继承**：
没有发生调用时从被覆盖的那一版产物里继承 `model_served`，并写 `model_served_inherited_from`
注明来源（有调用则以本次为准）。这样"这个值是继承的"可被看见，而不是冒充成本次自证。

   已修：还原结果必须"像正常文本"（只允许中日韩汉字/假名/CJK 标点/ASCII）才替换；真乱码那条路不受影响。

   （`跳过: {事件端不在库 / 目标不在库 / 字段残缺}`）。修完产物侧丢掉 166 条，导入的跳过从 167 降到 **8**。

## 4. 不要破坏什么

1. **别为了"看效果"而重跑**：规则类改动一律先干跑（免费，见 §0 与指南 §3.3）。
2. **别单方面收紧预测侧**：E4 的表与 gold 补标要**两侧同时**动（只收紧一侧，P/R 朝不可解释的方向走）。
3. **别用缓存重放冒充生效**：新旧规则的结果会并存，实测会把同一人物挂上 `统帅` 与 `将领` 两条。
4. **别动那份冻结的抽样基准**：`evaluation/review/sample_20260926.csv/.json` 是跨版本对比的定位基准，
   判定结果只回填 `_with_source` 那份（规范 §1）。
5. **别在有可信集合之前声称变好**：置信区间重叠就不声称（这是整改方案定的口径）。
6. **别把"已修未上线"当成已生效**：§3 那张表是唯一依据。
