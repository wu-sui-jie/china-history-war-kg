# frontend

**归属功能：F01 智能问答主界面 + F07 可视化知识面板（单页）。**

> ⚠️ 当前为离线阶段，本层尚未实现。需求见 docs/features/01-qa-main.md 与
> 07-knowledge-panel.md。技术选型：Vue 3 + TypeScript + Vite（架构文档）。

## 页面结构（规划）

- 左侧：对话区（会话历史、多轮追问、流式回答、引用、实体识别结果、手动纠正入口）。
- 右侧：知识面板区（F07）—— 实体卡 / 图谱子图 / 时间线 / 地图 / 引用证据。
- 顶部：朝代、战争类型筛选条件。
- 数据全部来自 SSE（data-contract.md），面板优先消费 `panel` 事件。

## 规划模块

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| `views/QaPage.vue` | F01 | 主页面布局。 |
| `components/chat/` | F01 | 输入框、消息流、引用气泡、实体纠正卡。 |
| `components/panel/` | F07 | EntityCard / SubGraph / Timeline / Map 组件与降级。 |
| `api/sse.ts` | 链路 | SSE 客户端、事件分发、取消/纠正重查。 |
| `stores/session.ts` | F01 | 会话历史本地持久化（刷新保留）。 |

## 关键约定（对应验收）

1. 页面不依赖登录、无旧版菜单/文案。
2. 知识面板各模块互不遮挡；坐标/时间缺失自动降级展示，不空白、不报错。
3. 筛选条件随请求体传给后端（不只注入提示词）。
4. 实体纠正 → 取消当前流 → 带 corrected_entities 与上一轮 history 重新发起。
